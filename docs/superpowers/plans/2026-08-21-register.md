# True Register + Ledger Receipts + Theme Switch + Punch Row

## Context

Three asks from Dan, one big + two small: (1) the Money register should read like a
real register — YNAB-style spreadsheet on desktop (running Balance, Outflow/Inflow,
receipt column) and YNAB-mobile-style date-grouped rows on the phone (his two
screenshots are the layout spec); receipts become attachable to ledger transactions
(his choice — new capability, reusing the proven capture pipeline). (2) A per-device
dark/light/system switch in Settings (localStorage, not DB). (3) Punch tiles reflow
to one row of six from `sm:` up (covers iPad portrait too).

Branch off main (e.g. `register`). **Ship order: migration 0031 to prod BEFORE
merge/push** (columns are nullable; old code unaffected).

## Verified foundations (explorer + designer both confirmed)

- page.tsx already loads ALL txns server-side (paged, created_at asc) and computes
  balances from the full set; RENDER_CAP=200 slices only the render. Balance work
  costs nothing extra.
- Receipts bucket RLS keys ONLY on folder[1]=auth.uid(); `signedReceiptUrls`
  filters on `${user.id}/` — a `{owner}/ledger/…` path needs no shared-code changes.
  `deleteShow` removes files by expense-derived paths only — ledger files unreachable
  from it. `deleteLedgerTransaction` exists, no storage cleanup today.
- Theme: dark in `:root` (+ `color-scheme: dark light`), light inside
  `@media (prefers-color-scheme: light)`; Tailwind v4 CSS-first (`@theme inline`
  maps vars→utilities, so re-theming = overriding vars at a selector); zero inline
  scripts today; no script CSP (deliberate) so a pre-paint script is safe.
- Punch grid `grid grid-cols-3 gap-2 max-w-md`; day card ~964px at desktop; six
  ~96-104px tiles fit inside `sm:max-w-2xl`; travel toggles wrap below — accepted.

### 4. Ledger receipt actions in `app/money/actions.ts` (mid)
Follow the file's guard idiom; all allowed on reconciled rows (receipts are audit
metadata like categorization — `setTransactionCategory` precedent; say so in doc
comments). Prefix-check EVERY caller path against `${user.id}/ledger/`:
- `attachLedgerReceipt(txnId, enhancedPath, originalPath)` — refuse when row
  already has either column ("This transaction already has a receipt.").
- `replaceLedgerReceipt(txnId, newEnhancedPath)` — refuse when receipt_original
  null; swap receipt_path; best-effort delete old file (warning-not-failure).
- `removeLedgerReceipt(txnId)` — ship NOW (a wrong photo on a reconciled row must
  not be permanent): null both columns first, best-effort remove both files.
- `deleteLedgerTransaction` — widen select to include receipt columns; after row
  delete, best-effort remove files; return gains optional `warning`.

### 6. MoneyRegister structure + LAYOUT (mid — the big one; layout per screenshots)
